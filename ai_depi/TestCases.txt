## إيه اللي المفروض تشوفه؟

في الـ **Relevant** cases، المتوقع غالبًا:

```text
HTTP 200
retrieval_status = sufficient
grounding_status = grounded
sources = [ ... ]
generation = { ... }
```

وفي الـ **Not Relevant** cases، بما إن `knowledge_mode = learning_materials_only`:

```text
HTTP 200
retrieval_status = insufficient
grounding_status = not_grounded
sources = []
generation = null
```

وده بالضبط بيثبت إن الـ **RAG مش بيخترع إجابة من برّه الـ learning materials** لما الـ relevant evidence مش موجود.

ملاحظة مهمة: الـ `/health` و`/ready` و`/docs` و`/redoc` و`/openapi.json` مش محتاجين JSON body أصلًا؛ الاختبارات الـ 12 دول هم الـ six learning endpoints اللي الـ Swagger schemas اللي بعتهم بتمثلهم.
